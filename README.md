## Publish on GitHub Pages
1. Create a new GitHub repository. A simple name is `amys-arms-umzinto`.
2. Set the repository to **Public** if you are using GitHub Pages on a free GitHub account.
3. Upload everything in this folder, keeping `assets/amys-arms-logo.jpg` inside the `assets` folder.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then click **Save**.
7. Wait a minute or two for GitHub Pages to publish the site.
8. Open the Pages URL shown by GitHub.
